# Floating Pet Interaction & Gesture Probe

Objective: Verify floating mascot gestures, state transitions, speech bubbles, and window touch passthrough behavior.

## Test Scenarios
1. Dragging: Smooth drag-and-drop to screen edges with magnetic snap.
2. Tap: Plays short interaction animation and displays status speech bubble.
3. Passthrough: Touches outside the pet bounds pass seamlessly to underlying Android applications.
4. Battery & Background: Animation loop suspends when screen turns off or full-screen app requests exclusive display.
