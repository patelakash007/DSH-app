# DSH Roadmap

Future milestones and planned developments for the DSH native client ecosystem.

---

## 1. Multi-Platform Native Expansion
- **iOS Port**: Porting the Flutter client and runtime bridge to iOS using native Swift background tasks.
- **HarmonyOS Next Adaptation**: Evaluating direct ArkTS / Flutter embedding for HarmonyOS Next devices.
- **Desktop Companion App**: Cross-platform Flutter desktop client for macOS, Linux, and Windows.

---

## 2. On-Device Native Capabilities
- **Local Small Language Models (SLMs)**: Native inference for lightweight on-device models via MediaPipe and llama.cpp bindings.
- **Enhanced Voice Pipeline**: Low-latency local voice activity detection (VAD) and offline speech-to-text.
- **Background Execution Resilience**: Advanced OEM battery optimization bypasses and persistent worker queues.

---

## 3. Extensibility & Ecosystem
- **Plugin Registry**: Community-driven plugin index for sharing custom agent tools and UI cards.
- **Enhanced MCP Support**: Deep bidirectional integration with Model Context Protocol servers.
- **Collaborative Sessions**: Multi-device live session synchronization and team collaboration features.
