# UI Polish, Motion, & Haptic Feedback Guidelines

Design specification for fluid animations, spring physics, and tactile haptic feedback.

## Principles
- Animation curves modeled on physical springs (`dampingRatio: 0.85`, `stiffness: 400`).
- Subtle haptic clicks for toggle switches, radial wheel ticks, and card taps.
- Consistent 60/120 fps frame budgeting with zero jank.
