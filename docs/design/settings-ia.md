# Settings Information Architecture

Complete hierarchical structure of user preferences and configuration categories.

## Categories
1. **Models & Providers**: API keys, endpoints, reasoning effort, parameters.
2. **Engine & Hosts**: Local native runtime, remote connection endpoints, SSH keys.
3. **Phone Control**: Accessibility, overlays, safety boundaries, permissions.
4. **Appearance**: Dynamic themes, custom launcher icons, font sizes.
5. **Pets & Companions**: Mascot selection, speech bubbles, interaction sensitivity.
6. **Diagnostics & About**: Logs, updates, open-source licenses, version metadata.
