# Reporting Security Vulnerabilities

Please keep sensitive exploit details, private tokens, credentials, and full diagnostic logs out of public issues and comments.

## Reporting a Vulnerability

To report a vulnerability responsibly:
1. Open the repository's security advisory portal or contact the maintainer privately:
   https://github.com/patelakash007/DSH-app/security/advisories
2. If private advisories are not enabled, create an issue requesting a private security contact channel without disclosing vulnerability details in public.

## What to Include in Your Report

- App version (`v1.0.0`) and architecture (arm64-v8a / x86_64)
- Attack vector, severity rating, and precondition requirements
- Minimal reproducible proof-of-concept using mock data
- Suggested remediation or mitigation steps if known

Do not submit real API keys, credentials, or private user session transcripts.
