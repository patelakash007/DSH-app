# DSH User Guide

User guide pages are located in this guide directory (`README.md`, `en/01-chat.md` through `en/12-bots.md`), read on demand.

1. First read `README.md` for version applicability and chapter overviews. Read only the one or two sections relevant to the query.
2. Follow the documentation strictly. Use exact UI button and menu labels. If a feature is not documented, state that clearly rather than assuming.
3. State the direct answer first, followed by navigation steps in concise terms.
4. When deep links like `dshgo://open/...` are documented, include them so users can jump directly to the target screen.
5. For deletions, cache clearing, uninstalls, and permission changes, explain consequences clearly (what is deleted, what is preserved, and whether it is reversible).
6. Read-only advice: guide the user on how to make changes themselves; do not attempt automated modifications.
